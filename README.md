# Portfólio jurídico — Vitória Tozzi

Landing page estática em HTML, CSS e JavaScript, sem framework.

## Abrir localmente
Abra `index.html` em um navegador. Para testar como site local, use a extensão Live Server do VS Code (opcional).

## Antes de publicar
- Revisar todos os textos e confirmar se a formação e participação em pesquisa continuam atuais.
- Preencher contatos reais na seção `#contato` do arquivo `index.html`. Não há números ou endereços fictícios.
- Adicionar currículo PDF apenas após revisão, se desejar.
- Se adicionar fotografia, inserir imagem otimizada em `assets/` com texto alternativo adequado.
- A página não anuncia advocacia: ajustar descrições e revisar normas aplicáveis antes de oferecer serviços profissionais.
- Fontes Playfair Display e DM Sans são carregadas do Google Fonts; se não houver conexão, serão utilizadas fontes alternativas.

## Publicar
É compatível com GitHub Pages, Netlify ou qualquer hospedagem de arquivos estáticos. Publique os arquivos preservando a estrutura da pasta.

## Arquivos
- `index.html`: conteúdo e semântica da página.
- `style.css`: identidade visual, layouts e responsividade.
- `script.js`: menu acessível, animações de entrada e atualização de ano no rodapé.
